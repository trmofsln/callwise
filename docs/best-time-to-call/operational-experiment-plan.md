# Preregistered operational proxy experiment

This is a new, separate experiment requested after the hotlead pilot failed to link completions. It does not reinterpret that pilot, access its locked test labels, or replace canonical `meeting_done` with `meeting_fixed`.

Population: source-13 current-replica employee-associated outgoing click-to-call records, terminal Answered/NotAnswered status, real call-start timestamps in the selected logging day. The employee field is only a population descriptor, not an as-of predictor. Vendor call start defines the calling hour. Call status/duration, current seller attributes and meeting outcomes are never pre-call predictors.

Before extraction, freeze dates and sampling: seed 43, up to 600 hash-ordered calls per day; train 4/9/14/19/24/29 May and 3/8/13/18/23 June 2026; validation 15/20/25/30 July and 4 August; test 27 August and 1/6/11/16 September. Maximum 12,600 rows. Indexed `date(entered_on)` selects the logging cohort; supplied/mutable logging timestamps are not treated as historical availability. The plan was inspected without execution and uses date/direction, UCID and meeting-call indexes.

Experimental target: at least one seller-consistent, directly linked or unambiguous reverse-linked physical DSR meeting whose **recording insertion time** lies from actual call start through 14 days and whose current result is non-null and not 9. A zero means no such linked record observed in the current replica, not proof that no true completed meeting occurred. Canonical meeting_done remains unknown for all rows; video completions are excluded because verification availability is unreliable. DSR status edits, incomplete linkage and retention are limitations. Record a further 7-day maturity grace assumption and embargo 21 days between partitions.

History path: sellers with earlier actual outbound events in the current observed scope. First-contact path: sellers with zero earlier events in the current replica since 1 May, verified by a DB search, not a claim of lifetime first contact. Scope is explicit and archive completeness false. Counts can describe cohort selection but will not be predictors while historical availability is unproven. Initially compare smoothed hour/day and regularized time-only logistic candidates. No current metadata is assumed historical.

Select only on validation using log loss plus Brier guard, fit Platt on validation only with adequate support, freeze artifacts and evaluate the locked final set once. Keep lead/seller chains isolated where relevant; cold sellers are disjoint across train/validation/test. Report AP, prevalence, Brier/log loss, fixed-budget predictive yield, seller-cluster intervals, and cohort/missingness limitations. Observational proxy scores are not causal completed-meeting lift. All outputs remain experimental and unapproved for production; canonical recommendations continue to abstain.
